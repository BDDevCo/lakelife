# Screen references

Files named after a role/screen are synthetic design compositions generated from the accompanying interactive reference. The `-phone` files show the full scrollable phone composition; `mobile-pair.png` shows the initial viewport of two of those compositions.

`prototype-home.png` is a local capture of the original `lakelife.html` with animations finished and fonts loaded locally. Its names, amounts and payment states are demonstration data, not production records.

Use `reference/index.html` to inspect all 35 selectable states. These images are visual guidance; actual application routes, data, prices and server rules remain authoritative.
