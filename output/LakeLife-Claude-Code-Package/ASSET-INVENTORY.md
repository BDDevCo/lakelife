# Approved LakeLife asset inventory

These are the current canonical asset files included with this package. Use [START-HERE-CLAUDE.md](START-HERE-CLAUDE.md) for full integration and image-use rules. All paths below are relative to this package root.

**General park-owner and renter imagery uses `park-homes.svg`: both the approved mobile home and RV.** Use an individual dwelling only when that context is known. Use the original house for lake homeowners, and housekeeping artwork for housekeeping.

The hero is generated illustrative scenery, not a real customer property or completed-job photograph. Do not use it as evidence. No new images were generated for this package.

`lakelife-ui-preview/dist/assets/` also contains runtime-ready copies used by the preview. The `renter.svg` filename there is a legacy RV alias, not a default illustration for every renter. The package contains all assets needed to open the offline preview; the full single-file HTML embeds its own copies.

PNG exports and SVG masters are supplied separately. Web implementation should prefer SVG for illustrations and preserve all proportions. The logo SVG embeds the original wordmark font; use its supplied PNG if an editor cannot render embedded fonts. Keep the original files and their provenance. The inventory records supplied assets; it does not create a new license grant.

The detailed handbook's `design-tokens.json` is a historical snapshot. Apply the current master handoff's token reconciliation and contrast guidance instead of importing a parallel theme.
