# LakeLife recruitment materials

Created 17 October 2026, with park owners leading and homeowners included.

- `../pdf/LakeLife-Brand-Guide.pdf`: the 12-page brand guide for the LakeLife team and creative partners. Includes identity, colors, type, voice, recruitment copy and answers to common questions.
- `../pdf/LakeLife-Recruitment-Pitch.pdf`: the three-page pitch, ready to share. The LakeLife.ai link on the last page is clickable.
- `../presentations/LakeLife-Recruitment-Pitch.pptx`: the editable presentation, with speaking notes. Text remains editable. It uses Bricolage Grotesque and Manrope, which need to be installed in the presentation editor to preserve the typography. The PDF preserves the intended appearance without installing fonts.
- `LakeLife-Brand-Guide.html`: editable source for the guide. Open it in a browser with the `assets` folder alongside it. Browser print settings: Letter, background graphics on, no margins, headers and footers off.
- `assets`: original logo, wave and service artwork extracted from the prototype, plus the project's cached webfonts for the HTML guide. The SVG mark preserves the original geometry. The full wordmark is typeset in the guide, not a new logo design.

The main call to action is LakeLife.ai. The park invitation links to `/for-parks`. Both addresses come from the project and the product owner's direction. Live network reachability was not verified during this task.

The deck describes the present product and invites a walkthrough. It does not promise live card processing, automatic rent collection, a free trial, a fixed setup time or guaranteed savings. Commercial terms and local service availability belong in the walkthrough.
